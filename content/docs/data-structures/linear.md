# Linear Data Structures

Linear data structures organize data in a sequential manner. Each element is attached to its previous and next adjacent in a single level.

### Common Examples
- **Array**: A collection of elements stored at contiguous memory locations.
- **Linked List**: A linear collection of data elements whose order is not given by their physical placement in memory.
- **Stack**: Follows Last-In-First-Out (LIFO) principle.
- **Queue**: Follows First-In-First-Out (FIFO) principle.
