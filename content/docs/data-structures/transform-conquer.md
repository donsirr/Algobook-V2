# Transform and Conquer

This technique works in two stages:
1. **Transformation**: Modify the instance to be easier to solve.
2. **Conquering**: Solve the transformed instance.

### Three Varieties
1. **Instance Transformation** (e.g., presorting).
2. **Representation Change** (e.g., heaps for priority queues).
3. **Problem Reduction** (e.g., reducing finding LCM to finding GCD).
