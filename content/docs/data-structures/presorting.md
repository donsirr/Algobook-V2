# Presorting

Many problems become easier if the input is sorted first.
- **Uniqueness Check**: (n \log n)$ instead of (n^2)$.
- **Searching**: (\log n)$ instead of (n)$.
- **Finding Mode**: (n \log n)$ instead of (n^2)$.
