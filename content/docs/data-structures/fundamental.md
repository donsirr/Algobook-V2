# Fundamental Data Structures

Data structures are specialized formats for organizing, processing, retrieving and storing data. They are designed to solve specific problems efficiently.

### Basic Classification
1. **Primitive**: Integer, Float, Char, Boolean.
2. **Non-Primitive**: Arrays, Lists, Files.

### Importance in Algorithms
Algorithms and data structures are tightly coupled. The choice of a data structure can significantly affect the efficiency (time and space) of an algorithm.
