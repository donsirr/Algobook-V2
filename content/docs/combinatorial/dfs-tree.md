# DFS Tree

When we perform a Depth-First Search on a graph, we can classify edges as:
- **Tree Edges**: Edges in the DFS tree.
- **Back Edges**: Edges connecting a node to an ancestor.
- **Forward/Cross Edges**: Other edges.
