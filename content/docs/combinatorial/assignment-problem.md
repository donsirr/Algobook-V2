# Assignment Problem

The assignment problem is a fundamental combinatorial optimization problem. In its most general form, the problem is as follows: There are a number of agents and a number of tasks. Any agent can be assigned to perform any task, incurring some cost.

### Objective
Assign each agent to exactly one task and each task to exactly one agent such that the total cost of the assignment is minimized.
