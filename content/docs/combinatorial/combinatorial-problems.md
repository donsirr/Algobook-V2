# Combinatorial Problems

Combinatorial problems involve finding a discrete object that satisfies certain conditions and has some desired property (like being of minimum size or having maximum value).

### Examples
- **Traveling Salesman Problem**: Find the shortest path through all cities.
- **Knapsack Problem**: Select items to maximize value within a weight limit.
- **Assignment Problem**: Assign jobs to workers to minimize cost.
