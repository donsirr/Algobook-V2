# Algorithm Efficiency

Efficiency is measured by two main factors:
1. **Time Complexity**: The amount of time an algorithm takes to run.
2. **Space Complexity**: The amount of memory an algorithm uses.

### Why efficiency matters?
As input sizes grow, the difference between an efficient and inefficient algorithm can be the difference between seconds and years of computation.
